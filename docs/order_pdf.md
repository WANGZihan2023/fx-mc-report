# 上传单子 PDF → 预填开始设置

在「开始设置」弹窗里可展开 **上传单子 PDF（可选）**。

## 用法

1. 侧栏 ① →「打开开始设置…」
2. 展开「上传单子 PDF」→ 选择老板/结构单 PDF
3. 核对预览：已自动填入 vs 仍需你选择
4. **手选**峰值引擎、是否使用校准、不确定证据是否人工确认（单子通常不含这些）
5. 点「确认开始设置」；若 PDF 带了 Barrier/Strike，主区「概率区间」可能已预选「绝对价位」并尝试填切点——务必再核一遍

解析失败会显示中文错误，可继续纯手动填写；**不会**因 PDF 而跳过必选校验。

## 能自动填入（识别自信时）

| 字段 | 说明 |
|------|------|
| 货币对 | `USD/AUD`、`AUDUSD`、`澳元兑美元` 等 |
| 看涨货币 | `看涨/看多 USD`；`看跌 X` 时推断另一腿 |
| 分档边界方式 | 有 Barrier/Strike → 倾向「绝对价位」；有 `0,2,4,6` 类切点 →「相对现价」 |
| 分档切点 | 仅当能自信得到 4 个切点时写入；否则只提示 Barrier/Strike 供手填 |
| 期限 | 仅展示参考，不参与必选校验 |

## 仍须点击选择

- 峰值引擎 `path_max` / `brownian_bridge`
- 是否使用校准参数
- 不确定证据是否人工确认
- 未识别出的货币对 / 看涨 / 分档方式与切点

依赖：`pypdf`（`requirements.txt`）。已配置 DeepSeek/LLM 时可选辅助抽取，**无 LLM 也可纯正则工作**。实现：`fx_report/order_pdf.py`。
