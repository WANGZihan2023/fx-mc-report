# 上传单子 PDF/图片 → 预填开始设置

在「开始设置」弹窗里可展开 **上传单子 PDF/图片（可选）**。

## 用法

1. 侧栏 ① →「打开开始设置…」
2. 展开「上传单子 PDF/图片」→ 选择老板/结构单（**PDF / JPEG / JPG / PNG**）
3. 核对预览：已自动填入 vs 仍需你选择
4. **手选**峰值引擎、是否使用校准、不确定证据是否人工确认（单子通常不含这些）
5. 点「确认开始设置」；若文件带了 Barrier/Strike，主区「概率区间」可能已预选「绝对价位」并尝试填切点——务必再核一遍

解析失败会显示中文错误，可继续纯手动填写；**不会**因上传而跳过必选校验，也**不会在 OCR/识图失败时编造字段**。

## 支持格式与文字提取

| 格式 | 提取方式 |
|------|----------|
| PDF | `pypdf`（可选 PyMuPDF）；离线可用 |
| JPEG / JPG / PNG | 优先本地 OCR：`Pillow` + `pytesseract`（需系统安装 **tesseract**）；失败且已配置支持视觉的 LLM（如 OpenAI `gpt-4o`）时，可选云端识图转录 |

**Docker / Railway：** 镜像默认**不**安装 tesseract（体积大）。部署环境若需离线读图，需自行在 Dockerfile 增加 `tesseract-ocr`；否则请上传可选中文字的 PDF，或配置视觉 LLM。DeepSeek 文本模型通常不支持识图，视觉路径依赖兼容多模态的网关/模型。

依赖：`pypdf`、`Pillow`（`requirements.txt`）；`pytesseract` 为轻量可选包装（仍需系统 tesseract）。已配置 LLM 时还可对提取后的文本做辅助字段抽取，**无 LLM 也可纯正则工作**。

实现：`fx_report/order_doc.py`（`fx_report/order_pdf.py` 为兼容再导出）。

## 能自动填入（识别自信时）

| 字段 | 说明 |
|------|------|
| 货币对 | `USD/AUD`、`AUDUSD`、`澳元兑美元` 等 |
| 看涨货币 | `看涨/看多 USD`；`看跌 X` 时推断另一腿 |
| 分档边界方式 | 有 Barrier/Strike → 倾向「绝对价位」；有 `0,2,4,6` 类切点 →「相对现价」 |
| 分档切点 | 仅当能自信得到 4 个切点时写入；否则只提示 Barrier/Strike 供手填 |
| 期限 | 仅展示参考，不参与必选校验 |

## 仍须点击选择

- 峰值引擎 `path_max` / `brownian_bridge`
- 是否使用校准参数
- 不确定证据是否人工确认
- 未识别出的货币对 / 看涨 / 分档方式与切点
