## 2. 这是什么？

一句话：**FX Analyse — 多货币对「展望期内最高日高」蒙特卡洛情报报告**——选好货币对与窗口后，自动抓新闻证据、跑蒙特卡洛，生成可下载的 PDF / HTML（中文或英文）。

---

## 3. 开始设置（第一次必做）

侧栏 **① 开始设置** →「打开开始设置…」。推荐用 **简洁（推荐）** 模式。

| 步骤 | 做什么 |
|------|--------|
| 货币对 | 从目录选（如 USD/AUD、AUD/USD），或自定义 |
| 看涨货币 | 选你关心哪边走强 |
| 上传单子（可选） | 支持 PDF / JPEG / PNG；可自动识别货币对、看涨、Barrier/Strike 等，请核对预填项 |
| 确认 | 点「确认开始设置」 |

确认后主区会出现：

- **现价（Spot）**
- **概率区间 / 分档**（相对百分比或绝对切点，二选一并设好）
- 侧栏 **③ 蒙特卡洛** 里可调 **交易日窗口**（看未来多少个交易日）

专家模式可手选峰值引擎、是否用校准参数、不确定证据是否人工确认；一般同事用简洁即可。

## 5. 若你有和我一样的 API 环境变量文件（一键使用）

同事若手头已有与管理员相同格式的文件（常见名：`railway-variables.env`、`.env`），**不必逐个粘贴 Key**，可在网页一键加载。

### 什么时候需要？

| 场景 | 要不要上传 |
|------|------------|
| **普通网页试用** | **不用**。云端 Railway 已配好 Key，登录后直接跑即可 |
| **想用自己的 Key**，或覆盖本会话配置 | 上传 `.env` → 一键加载到**本会话** |
| **想把 Key 永久写进云端**（所有人共用、redeploy 后仍在） | 除上传外，还需**管理员保存口令**才能「保存到云端」 |

### 在哪里点（约 3 步）

1. 打开网站并登录后，主区找到折叠面板 **「API / AI Key（按需；可上传 .env 一键加载）」** → 点开  
2. 滚到 **「仅本次会话 · 一键使用」** → 用文件选择器上传你的 `.env` / `railway-variables.env`  
3. 点主按钮 **「一键加载到本会话」** → 表格会显示已加载的变量名（值已打码）

上传后：**立刻对本浏览器会话生效**（可马上「运行分析」）。  
刷新页面或关掉标签后，本会话覆盖可能丢失——这是正常的；云端永久配置仍以 Railway Variables 为准。

### 「本会话」vs「保存到云端」

| 操作 | 作用 | 要不要管理员令牌 |
|------|------|------------------|
| **一键加载到本会话**（上传 `.env`） | 只影响当前浏览器会话；刷新可能丢 | **不需要** |
| **保存并持久化到 Railway Variables** | 写入云端环境变量，redeploy 后仍在 | **需要**「管理员保存口令」解锁（**不等于**页面访问密码） |
| **下载持久化 .env** | 导出本次新填写/上传的值，便于本机备份或 `push_env_to_railway.sh` | **需要**同上管理员解锁 |

管理员口令：向站点管理员索取。它对应环境变量 `ADMIN_SAVE_TOKEN`（未单独设置时应用内有默认值；云端若已覆盖则以平台为准）。普通试用同事**一般不必**做持久化。

### 文件格式示例（假占位符，勿填真 Key）

每行一个 `KEY=value`；支持空行与 `#` 注释；也可用 `export KEY=value`。后缀可以是 `.env`、无扩展名或 `.txt`，**按内容解析，不依赖文件名**。

```bash
# 示例：railway-variables.env / .env（以下均为假值）
NEWSAPI_KEY=your_newsapi_key_here
FINNHUB_API_KEY=your_finnhub_key_here
FRED_API_KEY=your_fred_key_here
TAVILY_API_KEY=your_tavily_key_here
ALPHA_VANTAGE_API_KEY=your_alphavantage_key_here
GROQ_API_KEY=your_groq_key_here
LLM_API_KEY=your_llm_key_here
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=your-model-name
```

常见变量名还包括：`TWELVE_DATA_API_KEY`、`BRAVE_SEARCH_API_KEY`、`DEEPSEEK_API_KEY`、`OPENAI_API_KEY` 等。有哪个填哪个；空行或未配置的源会自动跳过。

> **安全**：不要把真实 Key 发到公开群或提交 Git；不要把含密钥的备忘文件当「同事试用说明」群发。给同事试用请只转发**本文**（无密钥）。

## 6. 运行与下载

1. 确认开始设置 + 分档已选好  
2. 主区点 **「运行分析」**  
3. 等待约 **几分钟**（抓新闻 + 蒙特卡洛）  
4. 结果出来后，向下滚动下载 **PDF** / **HTML**

报告里若个别新闻链接失效，页面会标注；属正常现象，不必反复刷新。

---

## 7. 跑完还想再跑？

**不要狂按浏览器刷新**（容易卡住或感觉「死循环」）。

| 按钮 | 何时用 |
|------|--------|
| **再跑一份** | 设置不变，再生成一轮；上一份下载先保留，新结果出来后替换 |
| **新报告** | 要改货币对 / 看涨等 → 打开开始设置；上一份下载仍可保留 |
| **运行分析** | 也可直接再点（设置已齐时） |

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| 打不开网址 | 检查公司代理 / VPN；换网络或无痕窗口；仍不行找管理员 |
