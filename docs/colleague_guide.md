## 2. 这是什么？

一句话：**多货币对外汇「最高价 / 分档概率」Monte Carlo 情报报告**——选好货币对与窗口后，自动抓新闻证据、跑蒙特卡洛，生成可下载的 PDF / HTML。

---

## 3. 开始设置（第一次必做）

侧栏 **① 开始设置** →「打开开始设置…」。推荐用 **简洁（推荐）** 模式。

| 步骤 | 做什么 |
|------|--------|
| 货币对 | 从目录选（如 USD/AUD、AUD/USD），或自定义 |
| 看涨货币 | 选你关心哪边走强 |
| 上传单子（可选） | 支持 PDF / JPEG / PNG；可自动识别货币对、看涨、Barrier/Strike 等，请核对预填项 |
| 确认 | 点「确认开始设置」 |

确认后主区会出现：

- **现价（Spot）**
- **概率区间 / 分档**（相对百分比或绝对切点，二选一并设好）
- 侧栏 **③ 蒙特卡洛** 里可调 **交易日窗口**（看未来多少个交易日）

专家模式可手选峰值引擎、是否用校准参数、不确定证据是否人工确认；一般同事用简洁即可。

## 4. 侧栏常用项（按需看）

| 位置 | 说明 |
|------|------|
| 界面语言 | 中文 / English（只改页面文案） |
| **报告语言** | 中文 / English（PDF/HTML 正文语言；与界面语言独立） |
| **② 抓取与判定** | 「官方 / vault 头条」「**AI 检索员**」默认开启；可调「最多头条证据条数」 |
| **每份报告费用粗估** | 展开可看大约费用量级（非账单，仅规划参考） |
| API / AI Key | **一般不用填**——Tavily 等已由管理员配置 |

---

## 5. 运行与下载

1. 确认开始设置 + 分档已选好  
2. 主区点 **「运行分析」**  
3. 等待约 **几分钟**（抓新闻 + 蒙特卡洛）  
4. 结果出来后，向下滚动下载 **PDF** / **HTML**

报告里若个别新闻链接失效，页面会标注；属正常现象，不必反复刷新。

---

## 6. 跑完还想再跑？

**不要狂按浏览器刷新**（容易卡住或感觉「死循环」）。

| 按钮 | 何时用 |
|------|--------|
| **再跑一份** | 设置不变，再生成一轮；上一份下载先保留，新结果出来后替换 |
| **新报告** | 要改货币对 / 看涨等 → 打开开始设置；上一份下载仍可保留 |
| **运行分析** | 也可直接再点（设置已齐时） |

## 7. 历史回放（可选进阶）
